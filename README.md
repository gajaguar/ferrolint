# ferrolint

Extensible Python linter in Rust that runs custom rules as WASM plugins next to Ruff

## About

Extensible Python linter in Rust that runs custom rules as WASM plugins next to Ruff

## Requirements

Install the project's toolchain before running its commands.

## Usage

```bash
make install
make check
make test
```

Run `make help` for the full target list.
